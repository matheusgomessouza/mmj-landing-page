# My Money Journey Landing Page

## Tech Stack
- **Framework**: Next.js (Pages Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, CSS Modules
- **Testing**: Vitest (Unit), Cypress (E2E)
- **Perf**: Dynamic Imports, next/image

## Getting Started

### Installation
```bash
npm install
```

### Running
```bash
npm run dev
```

### Testing
- Unit: `npm run test`
- E2E: `npm run cypress`

### Build
```bash
npm run build
```
